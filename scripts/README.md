# Environment Setup & Verification Scripts

## Overview
The `scripts/` directory contains helper Linux shell scripts for verifying system dependencies and sourcing ROS 2 environments on Ubuntu 22.04 LTS.

## Planned Helper Scripts
- `check_env.sh`: Verifies ROS 2 Humble installation, Python 3 packages (`rclpy`, `xacro`), and colcon build tools.
- `setup_ros2_env.sh`: Sourcing script for automatic workspace environment setup.
